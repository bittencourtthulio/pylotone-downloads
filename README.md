# Pylot.One — downloads

Repositório oficial de distribuição. Contém somente documentação de instalação e releases, sem código-fonte.

Site: https://www.pylot.one

Baixe o instalador compatível com seu computador. O download não exige conta; cadastro e login acontecem no aplicativo. O uso exige assinatura ativa.

Os instaladores ainda estão em validação. Consulte o status de cada release antes de instalar.
